# 전시 모바일 잠금 설치 · Android 1.7

Android 9 이상이 필요합니다. 이 업데이트는 모바일 APK와 Android 기기 설정 변경입니다. PC 웹 콘텐츠 자동 업데이트만으로 적용되지 않습니다. 기존 게임·문자·씬 전환은 유지하며 Android 홈, 최근 앱, 알림창, 외부 앱으로의 이탈을 막습니다.

매일 한국시간 **12:45~18:00**에 전시를 표시합니다. 그 외 시간에는 화면을 검게 하고 밝기를 낮추며, 모바일 재생·진동·통신을 중단합니다. 휴대전화는 충전한 채 켜 두세요. 측면 전원 버튼으로 실제 화면을 끄면 다음 날 운영자가 다시 켜야 할 수 있습니다.

## 현장 Windows PC에서

1. `Exhibition-Mobile-Kiosk-Windows.zip`을 다운로드하고 **압축을 모두 풉니다**.
2. 전시 휴대전화 **한 대만** USB 데이터 케이블로 연결합니다. 폰의 개발자 옵션에서 **USB 디버깅**을 켜고, 이 PC의 연결 허용 안내를 승인합니다. 화면 잠금이 있으면 먼저 PIN으로 해제합니다.
3. `INSTALL.bat`을 실행합니다. 새 APK를 기존 앱 위에 설치해 저장된 PC 주소를 유지하고, Android 기기 소유자(Device Owner)로 등록한 뒤 전시 잠금을 시작합니다.
4. PC 창에 **LOCKED**가 나와야 완료입니다. 폰에서 홈·최근 앱·뒤로·상하단 스와이프를 직접 시도해 외부 화면이 열리지 않는지 확인한 뒤 관객에게 제공합니다. 앱 안의 문자 알림과 메시지 화면은 작품 기능이므로 계속 사용할 수 있습니다.

**STOP / NOT VERIFIED는 성공이 아닙니다.** 폰은 운영자가 보관하고 오류 문구를 전달해 주세요. 기존 Google/삼성 계정, 업무 프로필, 다른 기기 관리자, 제조사 정책 때문에 소유자 등록이 거부될 수 있습니다. 이 도구는 기기 초기화, 계정 삭제, 앱 데이터 삭제를 하지 않습니다. 실패를 일반 ‘화면 고정’으로 대체하지 않습니다. 데이터 삭제나 초기화가 필요할 경우 별도 승인과 백업 없이 진행하지 마세요.

새로 설치한 폰이라면 전시 PC의 모바일 접속 주소를 한 번 입력해야 합니다. 이후 `VERIFY.bat`을 실행해 실제 잠금을 다시 확인하세요. PC와 폰은 통신 가능한 네트워크에 있어야 합니다.

## 관리자 점검·복구

- `PAUSE.bat`: USB 디버깅을 승인한 운영 PC에서만 잠금과 전용 홈 설정을 해제하고 점검 모드로 전환합니다. 이때 폰을 관객에게 주지 마세요.
- `RESUME.bat`: 전시 잠금을 다시 적용하고 LOCKED 상태를 확인합니다.
- `VERIFY.bat`: 아무 설정을 변경하지 않고 잠금과 전시 앱의 전면 실행 여부를 확인합니다.
- 잠금 해제 명령은 Android 시스템 권한으로 보호되며 웹 화면이나 일반 앱에서 호출할 수 없습니다. 전시 중에는 USB 케이블을 관객이 조작하지 못하게 배치하세요.
- 기기를 재부팅하면 전시 앱이 기본 홈으로 열립니다. 기기 PIN이 설정되어 있으면 운영자가 한 번 잠금을 해제해야 할 수 있습니다. 측면 버튼의 화면 끄기/켜기는 유지합니다. 강제 재부팅 등 물리적 조작까지 소프트웨어가 막는다고 보장하지 않습니다.

## 개발 검증

`tests/kiosk-policy.py`는 실제 정책 코드의 미등록/일반 화면 고정/시스템 잠금 실패/키가드/관리자 복구 분기를 Android 서비스 대역으로 검사합니다. `tests/installer.py`는 기기 선택, 소유자 등록 실패 시 중단, 실제 LOCKED 판정과 관리자 응답 검증을 검사합니다. 실제 APK 컴파일과 기존 서명 검증을 수행했습니다. 현재 전시 기기에 연결할 수 없어 현장 기기의 물리 버튼·스와이프 검증은 설치 후 필요합니다.
