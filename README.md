# Resonant Fields · Parallax

두 전시 디스플레이와 Android 모바일을 동기화하는 전시 버전.

흡연 45초 → 비 80초 → 유튜브 100초 → 경찰차 160초 → 게임 190초 + 추가 정산 → 들개 145초. 기본 12분 반복이며 게임의 남은 특수 보석 정산만큼 늘어납니다.

- 실내 가로 화면, 실외 세로 화면, 모바일 화면. 출력 배경과 화면 위치는 고정됩니다.
- 게임은 60초씩 3판입니다. 판마다 특수 보석과 점수를 정산한 뒤 다음 보드가 내려오며, 3판 종료 후 시계로 전환하고 다음 장면으로 넘어갑니다.
- 유튜브 장면에는 지정된 영상이 표시됩니다. 타임라인만 조작할 수 있고 캐릭터와 모바일의 재생 위치가 함께 바뀝니다.
- 각 장면 중반에 `1씬 테스트`부터 `6씬 테스트`까지 수신합니다. 시계에는 잠금화면 알림, 영상·게임에는 상단 배너가 표시됩니다. 누르면 메시지 창으로 전환합니다.
- 메시지함에는 **딸**과 **저장되지 않은 번호** 두 대화가 있습니다. 딸과 지난주 오후에 주고받은 사전 메시지 5개가 있으며, 1~5씬 문자는 딸에게서, 6씬 문자는 이전 이웃인 저장되지 않은 번호에게서 도착합니다.
- 알림을 누르면 해당 대화가 열리고, 뒤로 가면 두 대화 목록으로 이동합니다. 답장은 현재 선택한 대화에만 저장됩니다.
- 전체 루프가 다시 시작되면 씬별 문자와 답장이 지워지고 딸과의 사전 대화 5개만 남으며, 저장되지 않은 번호의 대화는 비어 있는 상태로 돌아갑니다. 같은 루프에서 모바일을 재접속하면 현재 대화를 유지합니다. 기록은 PC의 `runtime-data/messages.sqlite3`에 저장하며 실제 SMS를 발송하지 않습니다.
- 캐릭터는 세로 기기를 들고 모바일의 게임·영상·메시지 상태를 픽셀 화면으로 보여줍니다.
- 듀얼 디스플레이 PC가 장면·게임 상태의 기준입니다. 다른 작품용 수신 이벤트는 `dist/exhibition-events.js`와 `integration/event-contract.json`에 준비되어 있습니다.

[Windows 테스트 ZIP 받기](https://github.com/suspiciouscloudgames/resonant-fields-parallax/releases/latest)

ZIP을 풀고 `TEST-THREE-SCREENS.bat`을 실행하면 세 창으로 테스트합니다. 실제 Windows 전시 PC에서는 `START.bat`을 실행합니다. 가로·세로 모니터가 각 한 대씩 연결되어 있어야 합니다. Edge 또는 Chrome이 필요하며 ZIP에는 Python 런타임이 포함되어 있습니다.

소스에서 테스트할 때는 Python 3과 Chrome이 설치된 Mac에서 `python3 exhibition-launcher.py --preview`를 실행합니다. 실제 Android는 같은 네트워크에서 실행 시 표시되는 PHONE 주소로 접속합니다. Android 소리는 첫 터치 이후 재생됩니다.

검증: 전체 2회 루프, 고정 메시지·루프별 초기화·재접속·저장소 재시작, 이벤트 재전송, 게임 3판 정산, 터치 입력, 영상 탐색 동기화, 고정 배경, 듀얼 모니터 전체화면·혼합 DPI를 검사했습니다. 실제 전시 PC와 Android 기기에서의 최종 확인은 별도로 필요합니다.
