# Resonant Fields · Parallax

두 전시 디스플레이와 Android 모바일을 동기화하는 전시 버전.

**조호연 님 / 외부 작품 연동 / GPT: [INTEGRATION.md부터 읽으세요](INTEGRATION.md).** 관객이 현재 씬의 문자 본문을 처음 확인할 때 `message.read` 이벤트가 씬당 한 번 발생합니다. 수신측 연결·중복 방지·예시와 코드 위치를 안내합니다.

관리형 전시 PC는 로그인 시 자동 실행되며, GitHub 최신 정식 릴리스의 `exhibition-update.json`을 1분마다 확인합니다. v0.3.18부터 다운로드와 검증을 마친 새 버전은 루프 종료를 기다리지 않고 바로 적용하며, 실행 실패 시 이전 버전으로 돌아갑니다. PC 재시작 후 열려 있던 모바일도 서버 변경을 감지하여 자동으로 새 내용을 불러옵니다. GitHub 확인 주기는 1분이며 다운로드 시간은 네트워크 상태에 따라 달라집니다. 기존 구버전에서 v0.3.18로 처음 넘어갈 때만 기존 루프 경계 규칙이 적용될 수 있습니다. 인터넷이 끊기면 설치된 버전을 계속 사용합니다. 관리형 설치는 `install-exhibition.ps1`로 구성하며 공유 기록과 모바일 연결 키는 사용자 폴더의 `Exhibition/runtime-data`에 유지됩니다. `exhibition-manager.py`의 로컬 제어로 시작·종료하며 Windows 자동 로그인은 Microsoft Autologon에서 한 번 설정합니다.

Android 모바일 1.7은 일반 화면 고정 대신 기기 소유자(Device Owner)의 전용 잠금을 사용합니다. **APK 설치와 현장 USB 설정이 필요하며 PC 자동 업데이트로 적용되지 않습니다.** 모바일 릴리스의 `Exhibition-Mobile-Kiosk-Windows.zip`을 풀고 `INSTALL.bat`을 실행합니다. 실제 LOCKED 상태를 확인하기 전에는 관객용 화면을 시작하지 않습니다. 홈·최근 앱·알림창·외부 창을 막고 관리자 점검은 USB 도구로만 허용합니다. 재부팅 시 기본 홈으로 복귀하며, 기기 PIN이 있으면 운영자의 첫 잠금 해제가 필요할 수 있습니다. 기존 PC 연결 주소·메시지·게임 기능과 측면 버튼의 화면 끄기/켜기는 유지합니다. [현장 설치와 복구 안내](android-kiosk/INSTALL-KIOSK.md)를 참고하세요. 기기 소유자 등록이 거부되면 데이터 삭제 없이 중단합니다.

운영 정책: 관람 중 임의 배포·업데이트를 금지합니다. 매 배포와 현장 적용은 사용자의 해당 업데이트에 대한 명시적 허가 후에만 진행합니다. 모바일 전용 릴리스에는 PC 자동 업데이트 매니페스트를 넣지 않습니다.

**운영 시간은 매일 한국시간 12:45~18:00입니다.** 18:00에 PC 두 화면과 모바일을 검정으로 바꾸고 배경음악·게임 소리·진동을 중단합니다. 기기는 켜진 채 대기하며 터치로 다시 표시되지 않습니다. 다음 날 12:45에는 첫 씬부터 새 루프를 시작합니다. Windows의 절전 방지와 전시 실행을 유지하고 폰도 충전한 채 켜 두어야 합니다. 기기를 물리적으로 끄거나 정전되면 자동 켜짐을 보장하지 않습니다. 모바일 앱 1.7은 PC 연결이 끊겨도 같은 시간표로 검정 화면을 유지합니다.

흡연 45초 → 비 115초 → 유튜브 100초 → 경찰차 185초 → 게임 190초 + 추가 정산 → 들개 325초. 기본 16분 반복이며 게임의 남은 특수 보석 정산만큼 늘어납니다.

- 실내 가로 화면, 실외 세로 화면, 모바일 화면. 출력 배경과 화면 위치는 고정됩니다. 전시 출력은 호환성이 확인된 독립 앱 창을 전체화면으로 실행하고 화면 가장자리와 안내 화면까지 커서를 숨깁니다. Esc 종료 메뉴에서만 커서를 표시하며, 전체화면 상태와 실제 화면 크기가 달라지면 자동 복구합니다.
- 자막은 씬 시작과 동시에 표시하며 긴 문장을 나눠 순서대로 보여줍니다. 글자 크기는 기존보다 12.5% 작게 조정했고, 비·충돌·개 등장 때는 사건을 먼저 볼 여백을 둡니다. 마지막 씬은 ‘하지만 그녀는 한 번도 혼자인 적이 없었다.’로 끝납니다. 모바일 문자·게임·영상은 자막과 독립적으로 진행됩니다.
- 모든 씬 경계에서 관객이 보고 있는 메시지·영상·게임을 닫고 1.8초 동안 잠금화면을 표시합니다. 게임·영상은 기기를 내려놓는 종료 구간부터 잠금을 유지해 다음 씬 전환 사이에 이전 문자 알림이 잠깐 나타나지 않도록 합니다. 전환 중에는 알림과 문자 재진입을 막으며, 이후 다음 씬의 모바일 화면을 따릅니다. 기존 씬 시간 안의 전환이므로 전체 루프 길이는 유지됩니다.
- 게임은 실제 플레이 60초씩 3판입니다. 문자 알림이 오거나 메시지 화면을 열어도 게임과 타이머는 계속 진행됩니다. 보석을 드래그하면 손가락을 따라 옆 보석과 자리를 바꾸고, 일치한 보석은 제거됩니다. 폰에서 즉시 애니메이션을 진행하고 PC의 최종 보드와 동기화하므로 네트워크 응답을 기다리는 입력 지연을 줄입니다. 보충 보석과 다음 판의 낙하는 폰의 화면 프레임마다 진행하고, 수신 지연으로 애니메이션 시간이 뒤로 튀지 않게 보정합니다. 판마다 특수 보석과 점수를 정산한 뒤 다음 보드가 내려오며, 3판 종료 후 시계로 전환하고 다음 장면으로 넘어갑니다.
- 거리에서 인물이 보이는 동안 PC와 모바일 모두에서 차량 환경음이 재생됩니다. 실제 비가 시작되면 빗소리가 올라오고 차량 소리는 낮아지며, 실내 복귀 시 자연스럽게 잦아듭니다. PC는 공통 호스트에서 한 번만 믹싱해 두 출력 창의 중복 재생을 막고, 모바일도 음악·환경음·게임 소리를 모두 출력합니다. 일시정지 시 소리도 멈춥니다. 실내에서는 제공된 「to the star」 음악을 반복 재생하며 실내외 전환에 약 1.5초 페이드를 적용합니다. 기본 음악 게인은 0.42, 게임 소리가 재생될 때는 0.10이며 게임 소리가 멈추면 기본 볼륨으로 돌아옵니다. 음원 출처와 CC0 표시는 `dist/media/ambience/sources.json`에 있습니다.
- 유튜브 장면에는 지정된 영상이 무음으로 표시되며, 배경음악만 기본 볼륨으로 재생됩니다. 타임라인만 조작할 수 있고 캐릭터와 모바일의 재생 위치가 함께 바뀝니다.
- 사용자 원고를 적용했습니다. 사전 대화 3개와 씬별 1·4·4·1·1·5개 문자이며, 본인 문자는 오른쪽 발신 말풍선으로 표시하고 수신 진동을 울리지 않습니다. 원고 길이에 맞춘 읽기 시간, 문자 간격과 씬 길이는 [MESSAGE-TIMING.md](MESSAGE-TIMING.md)에 정리했습니다. 실외 사건은 마지막 문자를 읽을 시간을 확보한 뒤 시작합니다.
- 모바일 앱 1.2에서 새 수신 문자마다 짧게 두 번 진동합니다. 메시지 화면을 읽는 중에도 울리며, 기존 대화·관객 답장·재접속으로 다시 불러온 문자에는 울리지 않습니다. 이 기능은 Android 앱 업데이트와 앱 알림 권한 허용이 한 번 필요합니다. 권한이 꺼져 있으면 전시 시작 화면의 ‘문자 진동 알림 허용’에서 켭니다.
- 처음 메시지함에는 **딸**과 주고받은 사전 메시지 3개만 있습니다. 1~5씬은 딸과 본인의 대화이며, **저장되지 않은 번호** 대화는 6씬에서 이전 이웃의 첫 문자가 도착할 때 처음 나타납니다.
- 사전 문자와 1~5씬 문자는 한 통마다 7일 간격, 한국 시각 오후 1시~4시 이전으로 표시합니다. 마지막 들개 씬 문자는 실제 도착 날짜·시각입니다. 표시 날짜와 실제 수신 시각을 분리하여 알림·진동 타이밍은 유지합니다.
- 알림을 누르면 해당 대화가 열리고, 뒤로 가면 두 대화 목록으로 이동합니다. 답장은 현재 선택한 대화에만 저장됩니다.
- 전체 루프가 다시 시작되면 씬별 문자와 답장이 지워지고 딸과의 사전 대화 3개만 남으며, 저장되지 않은 번호의 대화는 목록에서 사라집니다. 같은 루프에서 모바일을 재접속하면 현재 대화를 유지합니다. 기록은 PC의 `runtime-data/messages.sqlite3`에 저장하며 실제 SMS를 발송하지 않습니다.
- 캐릭터는 세로 기기를 들고 모바일의 게임·영상·메시지 상태를 픽셀 화면으로 보여줍니다.
- 듀얼 디스플레이 PC가 장면·게임 상태의 기준입니다. 다른 작품용 수신 이벤트는 `dist/exhibition-events.js`와 `integration/event-contract.json`에 준비되어 있습니다.

[Windows 테스트 ZIP 받기](https://github.com/suspiciouscloudgames/resonant-fields-parallax/releases/tag/v0.3.27-continuous-audio)

ZIP을 풀고 `TEST-THREE-SCREENS.bat`을 실행하면 세 창으로 테스트합니다. 실제 Windows 전시 PC에서는 `START.bat`을 실행합니다. 가로·세로 모니터가 각 한 대씩 연결되어 있어야 합니다. Edge 또는 Chrome이 필요하며 ZIP에는 Python 런타임이 포함되어 있습니다.

소스에서 테스트할 때는 Python 3과 Chrome이 설치된 Mac에서 `python3 exhibition-launcher.py --preview`를 실행합니다. 실제 Android는 같은 네트워크에서 실행 시 표시되는 PHONE 주소로 접속합니다. Android 소리는 첫 터치 이후 재생됩니다.

검증: 전체 2회 루프, 고정 메시지·루프별 초기화·재접속·저장소 재시작, 이벤트 재전송, 게임 3판 정산, 터치 입력, 영상 탐색 동기화, 고정 배경, 듀얼 모니터 전체화면·혼합 DPI를 검사했습니다. 실제 전시 PC와 Android 기기에서의 최종 확인은 별도로 필요합니다.
